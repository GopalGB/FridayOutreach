# Code of Conduct

Participants are expected to be respectful, specific, and constructive. Harassment, discrimination, threats, doxxing, sexualized attention, unwanted contact, and attempts to expose private data are not acceptable.

Keep discussions focused on code, evidence, and users. Use fictional or sanitized examples. Maintainers may edit, reject, or remove contributions that violate this standard or put people, third parties, or private data at risk.

Use GitHub’s report controls for harassment or private-data abuse. Security vulnerabilities belong in the [private advisory form](https://github.com/GopalGB/FridayOutreach/security/advisories/new), not a public issue.

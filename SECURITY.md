# Security policy

GitHub private vulnerability reporting is enabled for this repository. Report vulnerabilities through the [private advisory form](https://github.com/GopalGB/FridayOutreach/security/advisories/new), not a public issue.

For ordinary bugs, use a fictional or sanitized fixture. Never include credentials, `.env` contents, private leads, mailbox responses, native binaries, or raw private logs. A report should state the affected version or commit, a minimal safe reproduction, impact, and any safe mitigation. Do not publicly disclose an unpatched vulnerability.

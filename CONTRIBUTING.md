# Contributing

Start with a focused issue or small documentation correction. Fork, branch, and keep the pull request narrow. [Issues #1](https://github.com/GopalGB/FridayOutreach/issues/1), [#2](https://github.com/GopalGB/FridayOutreach/issues/2), and [#3](https://github.com/GopalGB/FridayOutreach/issues/3) are good first issues; larger work is marked help wanted in [ROADMAP.md](ROADMAP.md).

Use Python 3.11+ and Node.js on `PATH`. The local commands below match the pinned CI tool versions and require no MAX tooling or model subscription:

```sh
python3 scripts/setup.py --core
.venv/bin/python -m ensurepip --upgrade
.venv/bin/python -m pip install --no-cache-dir --index-url https://pypi.org/simple ruff==0.15.7 mypy==1.9.0 bandit==1.9.4
.venv/bin/python scripts/check_docs.py
export PATH="$PWD/.venv/bin:$PATH"
command -v node
node --version
LEAD_COLLECTOR_TMPDIR="$(mktemp -d "${HOME}/lead-collector-verify.XXXXXX")"
export TMPDIR="$LEAD_COLLECTOR_TMPDIR"
.venv/bin/python scripts/verify.py
.venv/bin/mypy --strict --follow-imports=skip scripts/reacher_smtp_runner/patch_reacher_core.py
.venv/bin/python -m bandit -r lead_collector scripts -ll
```

Optional native and AI-artifact tests may skip in a clean core checkout. Use fictional fixtures and sanitized bug reports; never include real lead rows, credentials, `.env` content, mailbox data, or private records. Describe the smallest reproduction, expected result, actual result, and named error.

Do not hand-edit autogenerated locks or the release manifest; the current manifest is release metadata and a maintainer regenerates it. Contributions to FridayOutreach are licensed under the [MIT License](LICENSE). Retain applicable third-party licenses and copyright notices.

`scripts/check_docs.py` checks local Markdown file paths and heading fragments, JSON examples against the documented function-tool schemas, GitHub issue-form YAML structure, fenced code closure, and Mermaid diagram declarations. It is fully offline: it does not check remote URL availability or render Mermaid diagrams.
